- **`fastmail mcp --http` refuses requests from web pages.** The HTTP server accepted any `Host`, and a request without a token is answered with your own, so a web page that rebinds its hostname to 127.0.0.1 could read and send your mail; it now refuses a `Host` other than the bind address, `localhost`, `127.0.0.1` and `[::1]`, and an `Origin` other than its own. A proxy that forwards a name of its own, such as a service name, is allowed with `--allowed-host` or `FASTMAIL_MCP_ALLOWED_HOSTS`.
