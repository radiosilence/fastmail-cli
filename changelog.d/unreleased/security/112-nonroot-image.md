- **The container runs as non-root.** The MCP server holds a mail account's token for each request and parses mail from the internet, so the image now builds on distroless's `nonroot` variant and runs as uid 65532 rather than root. Its home moves from `/root` to `/home/nonroot`: a config or cache mounted under `/root` is no longer found, so mount it under `/home/nonroot` instead.
